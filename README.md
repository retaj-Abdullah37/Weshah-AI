# Weshah

An AI-powered Arabic literary analysis project focused on Andalusian Muwashahat.

## Overview
The model was trained and fine-tuned using Google Colab to analyze poems, generate simplified explanations, provide cultural introductions, and identify difficult words and their meanings using NLP and LLM techniques.

## Technologies Used
- Python
- Google Colab
- NLP
- LLM
- Pandas
- Hugging Face

## Features
- Poem analysis
- Simplified explanations
- Cultural introductions
- Difficult word detection
- Meaning generation

## Project Files
- `.ipynb` notebook for training and experimentation
- `.py` file for clean Python implementation
- `Weshah_Poster.pdf` for project poster
- `Weshah_Demo.pdf` for demo and outputs
